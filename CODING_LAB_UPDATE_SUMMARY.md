# Medical Coding Lab Expanded Update

This version expands the Medical Coding Practice Case into a structured academic simulator.

## Added

- Multi-case coding practice with fictional patient charts
- Primary diagnosis selection
- Secondary condition/additional diagnosis selection
- Procedure, service, surgery and supply code selection
- Laboratory, imaging and observation code selection
- Medication/drug terminology and drug classification code selection
- Guided hints for each case
- Coding query training workflow
- Visible scoring result
- Missing, extra and correct code review
- Personalized recommendations for the student
- Instructor answer-key view
- Searchable teaching code library
- Coding systems reference with official-source links

## Included coding/terminology systems

- ICD-10-CM
- ICD-11 reference concepts
- ICD-10-PCS sample inpatient procedure codes
- CPT sample professional service/procedure codes
- HCPCS Level II sample codes
- SNOMED CT sample clinical terminology concepts
- LOINC sample observation and lab codes
- RxNorm sample drug concepts
- ATC sample drug classification codes
- NDC official-source link for product-level drug identifiers

## Academic and legal note

The simulator contains an expanded educational code library and links to official code sources. It does not embed every code from every official code set because complete code sets are very large, frequently updated, and some systems such as CPT require official/licensed access. The module is intended for university training and portfolio development only.
