# Mini Quiz Game Update

Updated Mini Quiz Game to provide a more academic and game-like quiz experience.

## Changes
- Each course contains 100 specialist questions.
- Questions are generated as non-identical items with topic labels and difficulty levels.
- Difficulty pathway is shown to learners:
  - Easy: Questions 1-30
  - Intermediate: Questions 31-70
  - Advanced: Questions 71-100
- Answer choices are shuffled deterministically so the correct answer appears in different option positions.
- Feedback now uses motivational correct/incorrect messages.
- Correct answers show a celebration message.
- Incorrect answers show a supportive sad-face feedback message and guidance.
- Each question includes a topic tag and explanation.
