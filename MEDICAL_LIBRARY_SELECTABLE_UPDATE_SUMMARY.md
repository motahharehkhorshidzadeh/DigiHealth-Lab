# Medical Library Selectable Update

- Audit & Missing Docs was removed from the visible platform navigation and dashboard map.
- Medical Library was redesigned as a specialty-based selectable library.
- Removed numeric stat tiles and legal/stat summary blocks from the library screen.
- Replaced free-text search with dropdown selections: main academic field, specialty/sub-field, and book/resource.
- Books are not displayed automatically; results appear only after the user selects criteria and clicks Find Selected Books.
- Book cards include illustrated medical cover-style visuals and links to official publisher/open/standards pages.
